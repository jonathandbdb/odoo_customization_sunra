Backend - Parche de una regresion de core (Odoo 19)

web_notebook_wrap_fix

Restaura el corte de linea dentro del contenido de las pestanas (notebook) del backend, roto por una regresion de CSS del core de Odoo 19.

Objetivo

El commit de core 7d26b3444f61 ("[FIX] web: adjust SCSS for vertical notebook", odoo/odoo#279098, task-5933892), mergeado a la serie 19.0 el 04/09/2026, movio la regla white-space: nowrap de .o_notebook .nav-item (solo las solapas) a .o_notebook.horizontal (el notebook completo). Al heredarse esa propiedad, el contenido de cualquier pestana dejo de poder cortar linea. Este modulo restaura el corte de linea del contenido con una sola regla CSS de mayor especificidad, sin tocar la regla de las solapas ni ningun modulo funcional.

Funcionalidades principales

Regresion parcheada Commit de core 7d26b3444f61 (odoo/odoo#279098, task-5933892), mergeado a la serie 19.0 el 04/09/2026. Extendio el white-space: nowrap de las solapas del notebook a todo su contenido.
Sintoma visible En cualquier pestana que mezcle botones (inline) con un widget one2many/many2many (inline-block), el widget queda pegado al lado de los botones y se desborda a la derecha: scroll horizontal y columnas fuera de pantalla. Caso reportado: pestana "Deudas" del formulario de pagos (account_payment_pro).
Como lo arregla Un unico bloque SCSS apunta a .o_notebook.horizontal > .o_notebook_content (3 clases, mas especifico que el selector del core) y le devuelve white-space: normal. Las solapas no se tocan: siguen heredando el nowrap del core.
Auto-instalacion y vida util auto_install: True (depende solo de web): se instala solo apenas esta presente en el deploy, sin paso manual. Es un parche temporal: se desinstala y se borra cuando Odoo corrija la regresion en el core.

Configuracion

  1. No requiere configuracion: al ser auto_install, el modulo queda instalado solo apenas esta presente junto con web en la base.
  2. Para confirmar que esta activo: Ajustes -> Aplicaciones, buscar "web_notebook_wrap_fix" y verificar que figura Instalado.
  3. Cuando Odoo publique el fix de la regresion en el core (seguimiento de 7d26b3444f61 / odoo/odoo#279098), o al actualizar a una version de core donde ya este corregida: desinstalar este modulo y borrar su carpeta del repositorio.

Detalle tecnico

El modulo no define modelos, vistas, seguridad, wizards ni datos: es un unico archivo static/src/scss/notebook_wrap.scss cargado en el bundle web.assets_backend. La regla usa .o_notebook.horizontal > .o_notebook_content (3 clases, contra las 2 del selector .o_notebook.horizontal del core) para ganar por especificidad y fijar white-space: normal en el contenido, sin usar !important ni depender del orden de concatenacion del bundle de assets.

La regresion es generica del framework web, no especifica de un modulo: afecta a cualquier pestana del backend que combine contenido inline y un widget inline-block. El caso de account_payment_pro es el sintoma reportado, no la causa; este modulo no modifica ese ni ningun otro modulo funcional.

Dependencias

  • web (core) - unica dependencia; el fix actua sobre el componente notebook del framework de backend.
  • Sin dependencias de terceros ni de Enterprise.

Sitio web - Permisos de acceso

website_menu_access

Oculta la app Sitio web del backend a los usuarios internos que no tienen el permiso de Sitio web.

Objetivo

Por defecto, Odoo muestra la app Sitio web a todo usuario interno. Este modulo la limita a quienes tienen el grupo Sitio web (Editor restringido), de modo que perfiles como Administracion dejen de verla.

Funcionalidades principales

Menu restringido El menu raiz de Sitio web solo se muestra a los usuarios con el grupo Editor restringido de Sitio web.
Sin cambios de datos No agrega modelos, campos ni grupos nuevos.
Desinstalacion limpia Al desinstalar, el menu vuelve a ser visible para todo usuario interno, como en el core.

Configuracion

  1. Ir a Ajustes - Usuarios y compañias - Usuarios y abrir el usuario que no debe ver la web.
  2. En la pestaña de permisos, dejar el campo "Sitio web" vacio.
  3. Guardar. El usuario no vera mas la app Sitio web al recargar el navegador.

Casos en que el usuario sigue viendo la app

Algunos permisos incluyen el de Sitio web, por lo que el usuario sigue viendo la app aunque "Sitio web" este vacio:

  • Ajustes = Administracion.
  • Ventas = Administrador.
  • Los permisos de gestor de eventos, eLearning y reclutamiento web.

Los programas de descuento y lealtad no los modifica este modulo: se ocultan quitando Ventas = Administrador.

Detalle tecnico

Reemplaza los group_ids del menu website.menu_website_configuration (en el core, base.group_user) por website.group_website_restricted_editor. Un uninstall_hook restituye base.group_user.

Los grupos que implican el permiso de Sitio web estan definidos en website/security/website_security.xml y website_sale/security/res_groups.xml.

Contabilidad - Importacion de datos

base_import_ux

Agrega dos ajustes puntuales al asistente de importacion nativo de Odoo para poder cargar el estado de cuenta CSV de Mercado Pago como extracto bancario sin editar el archivo a mano.

Objetivo

El estado de cuenta que exporta Mercado Pago trae, antes del encabezado real, filas de resumen (titulo, totales y una fila en blanco) que el asistente nativo no puede saltear, obligando a editar el CSV a mano antes de cada conciliacion. Este modulo agrega dos ajustes de UX sobre el wizard de import existente, sin crear modelos, tablas ni pantallas nuevas.

Funcionalidades principales

Filas de cabecera a saltear Nuevo input "Header rows to skip" junto al checkbox "Use first row as header": descarta las primeras N lineas crudas del archivo CSV (incluida una fila en blanco) antes de parsear. Default 0 (comportamiento nativo intacto).
Fecha DD-MM-YYYY en extractos Al importar transacciones bancarias ("Importar transacciones" de un diario), el "Formato de fecha" abre prefijado en DD-MM-YYYY. Queda editable y, si el archivo no matchea, la autodeteccion nativa sigue funcionando como respaldo.
Alcance: solo CSV El recorte de filas aplica unicamente a archivos CSV. Para xlsx/xls/ods la opcion queda visible pero es no-op: el import se comporta igual que el asistente nativo.
Sin datos persistentes Ambos ajustes son opciones del wizard de import (no campos ORM ni configuracion en Ajustes): no agregan columnas ni tablas a la base de datos.

Configuracion: receta para el extracto de Mercado Pago

  1. Ir al diario correspondiente -> Importar transacciones -> seleccionar el CSV exportado por Mercado Pago tal cual, sin editarlo.
  2. En las opciones del asistente: Header rows to skip = 3 (2 filas de resumen + la fila en blanco que las separa del encabezado), separador ;, formato de miles ., formato de decimales ,. El "Formato de fecha" ya abre prefijado en DD-MM-YYYY.
  3. Mapear columnas: RELEASE_DATE -> Fecha, TRANSACTION_TYPE -> Etiqueta, TRANSACTION_NET_AMOUNT -> Importe, PARTIAL_BALANCE -> Cumulative Balance.
  4. Mapear REFERENCE_ID a Referencia, o dejarlo sin mapear. Nunca mapear a "ID externo": Mercado Pago repite ese identificador de forma legitima en varias filas, y usarlo como ID externo hace que las filas se pisen entre si.

Detalle tecnico

El modulo extiende el modelo transient base_import.import (override de _read_csv, sin decorador especial) que recorta las primeras N lineas crudas del archivo antes de delegar en el parser nativo, evitando que el core cuente mal la fila en blanco o se confunda con anchos de columna disparejos. En el cliente, un unico patch OWL (patch() sobre BaseImportModel.prototype, en init() y updateData()) registra la opcion "Header rows to skip" y prefija la fecha DD-MM-YYYY solo cuando el import es de extractos bancarios; un patch de template (t-inherit) agrega el input numerico junto al checkbox de encabezado.

El recorte solo aplica a CSV con encoding compatible ASCII/UTF-8 (utf-8, latin1, windows-1252, etc.). Encodings multi-byte como UTF-16/UTF-32 no estan soportados: para esos casos hay que convertir o editar el archivo antes de importar.

Dependencias

  • base_import (core) - asistente de importacion generico que se extiende.
  • account_bank_statement_import_csv (Enterprise) - flujo de "Importar transacciones" de extractos bancarios sobre el que aplica el default de fecha.
